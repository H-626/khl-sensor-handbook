# KHL SensorHub 本地部署与分享教程

这套本地版把一个网站拆成了三份独立的网页，分别对应中文、英文、中英对照，并且去掉了密码（只在本地局域网内使用，适合分享到 Teams）。

## 三个网页

| 页面 | 地址 | 内容 |
| --- | --- | --- |
| 中文版 | `http://localhost:8000/index-zh.html` | 全中文界面 |
| 英文版 | `http://localhost:8000/index-en.html` | 全英文界面 |
| 中英对照版 | `http://localhost:8000/index-both.html` | 中文和英文并排显示 |

右上角的「中文 / EN / 对照」就是在这三个独立网页之间跳转。

## 传感器管理接口

右上角的「管理」按钮打开 `http://localhost:8000/admin.html`，可以：

1. 查看已有传感器，并删除不需要的物理量。
2. 添加实验室已有的新传感器，字段格式与网站传感器卡片一致（物理量 ID、中英文名称、简介、原理、型号、价格、层级、配套组合、适用场景）。
3. 直接编辑完整 `sensors.json` 做批量修改。

管理页保存后，回到主网页刷新即可看到变化。数据会写入本机的 `sensors.json` 文件。

## 本地启动步骤

1. 确认电脑装了 Python（在终端输入 `python --version` 能看到 3.x 即可）。
2. 双击项目文件夹里的 `start.bat`。
3. 弹出的黑色窗口不要关闭，它会显示两行地址：
   - 本机访问：`http://localhost:8000`
   - Teams 分享：`http://192.168.x.x:8000`（x.x 是你电脑在局域网里的 IP）
4. 把局域网地址发到 Teams 群里，其他成员在同一个网络下就能打开，无需密码。

关闭黑窗即停止分享。再次双击 `start.bat` 即可重新启动。

## 分享到 Teams 的注意事项

- 成员必须在同一个局域网（或校园网/VPN 内网）。
- 如果别人打不开，通常是 Windows 防火墙第一次拦截了 Python，允许“专用网络”访问即可。
- 你的电脑需要保持开机，并且黑窗保持打开，别人才访问得到。
- 这个本地版不需要密码；如果之后要放到公网（GitHub Pages），请继续使用原来的 `index.html`（带密码的加密版本）。
